# Good Measure — Motion standards

공통 모듈: `public/motion.js`, 스타일: `public/motion.css`. 수치는 `design/tokens.json`에서 관리하고 `npm run design:tokens`로 반영합니다.

## 자주 쓰는 패턴

```html
<!-- 문장 속 단어가 마스크 아래에서 순차 등장 -->
<h2 data-motion="words">Good ideas. Better made.</h2>

<!-- 글자 단위. 실제 줄바꿈은 단어 경계 유지 -->
<p data-motion="chars">Every detail matters.</p>

<!-- 블록 전체가 24px 아래에서 등장 -->
<div data-motion="rise">...</div>

<!-- 이미지 영역의 가림막이 위로 열림 -->
<div data-motion="reveal"><img src="..." alt="..."></div>

<!-- 버튼 문구 롤오버 + 약한 포인터 반응 -->
<button data-roll data-magnetic>Let’s talk <span>↗</span></button>
```

모듈에서 `initMotion()`을 한 번 호출합니다. 기본은 첫 진입 때만 재생합니다. 의도적으로 반복하려면 `data-motion-repeat`을 추가합니다. `data-no-split`은 텍스트 분할 제외 영역입니다. 내용이 동적으로 바뀌는 상태 메시지·입력 필드·시간에는 적용하지 않습니다.

## 타이밍

| 역할 | 기준 |
| --- | --- |
| 단어·문장 등장 | 900ms |
| 단어 간 지연 | 55ms, 총 지연 최대440ms |
| 이미지 마스크 | 1100ms |
| 필터·아코디언·모달 | 500ms |
| 올라오는 블록 거리 | 24px |
| 공통 이징 | cubic-bezier(.22,1,.36,1) |

문장이 길어도 총 지연을 제한해 마지막 단어를 오래 기다리지 않게 합니다. 실제 페이지에서는 제목·소개 문구·서비스 설명에 적용하고, 페이지의 모든 UI를 무조건 숨기지 않습니다.

## 스크롤·포인터

- IntersectionObserver로 화면 진입을 감지합니다. 사용자의 스크롤을 가로채지 않습니다.
- 히어로 오브젝트는 작은 포인터 이동과 최대28px의 스크롤 이동을 적용합니다.
- 프로젝트의 View project 표시는 마우스를 따라 움직입니다. 카드 가장자리64px 안쪽으로 제한합니다.
- 버튼 이동은 중심 거리의10~12%로 제한합니다. 터치에서는 포인터 추적을 사용하지 않습니다.
- 필터는 이전·이후 위치 차이를 이용해 자연스럽게 재배치합니다. 숨겨진 항목은 포커스 대상에서 제외됩니다.
- 서비스 아코디언은 실제 높이를 측정해 애니메이션합니다. 빠른 연속 클릭은 이전 애니메이션을 취소하고 현재 높이에서 이어갑니다.
- 마키와 그래픽의 연속 움직임은 화면 밖에서 일시 정지합니다.

## 접근성·안전한 기본값

- OS의 `prefers-reduced-motion`을 우선 적용하고, 푸터의 Motion on/off로 움직임을 끌 수 있습니다. 선택은 해당 브라우저에 저장합니다.
- 스크린리더에는 분할 전 문장을 한 번만 제공합니다. 시각용 단어 조각은 읽기 대상에서 제외합니다.
- 원래 DOM의 강조·줄바꿈·자연스러운 단어 경계를 유지합니다. 글자 분할은 가능한 경우 Intl.Segmenter로 처리합니다.
- JS 모듈이 로드되지 않아도 기본 콘텐츠는 보입니다. 모션 준비가 완료된 뒤에만 숨김·등장을 활성화합니다.
- Motion off에서는 진행 중인 애니메이션을 취소하고 텍스트·이미지를 즉시 표시합니다.

브라우저 검증은 로컬 페이지와 `/design-system.html#motion`의 재생 예제로 진행합니다.
