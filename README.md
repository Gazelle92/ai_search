# Hummman AI 포트폴리오 검색 데모

독립 프로젝트 위치: `C:/Users/hutsw/Desktop/작업폴더/hummman_project/ai_search`

기존 `hummman_website`는 읽기만 했으며 코드, 환경변수, Prismic 데이터를 수정하지 않았습니다. 디자인 작업 없이 기본 HTML 입력창과 결과 표시만 구현했습니다. 운영 배포는 하지 않았습니다.

## 실행

Node.js 22 이상을 사용합니다. 이 폴더에서:

```powershell
npm install
Copy-Item .env.example .env
```

`.env`의 `GEMINI_API_KEY=` 뒤에 본인의 서버용 API 키를 입력하고 저장하세요. 키는 채팅에 보내지 마세요. [Google AI Studio](https://aistudio.google.com/apikey)에서 키를 발급받으세요. 무료 사용을 원하면 해당 프로젝트의 Free Tier 상태를 확인하세요.

```powershell
npm start
```

브라우저에서 <http://127.0.0.1:3100>을 엽니다. 개발 중 자동 재시작은 `npm run dev`를 사용합니다. 종료는 실행 중인 터미널에서 Ctrl+C입니다. 환경변수를 변경하면 서버를 재시작하세요.

키 없이도 화면, 키 미설정 안내, **공개 데이터 연결 확인 → 프로젝트 목록 가져오기**를 사용할 수 있습니다. AI 검색은 키를 설정한 뒤 검색 버튼을 누를 때만 Gemini API를 호출합니다. 무료 한도는 계정·모델에 따라 다르며 유료 프로젝트에서는 과금될 수 있습니다. 가짜 AI 결과나 키워드 검색 대체 결과는 제공하지 않습니다.

| 변수 | 기본값 | 용도 |
| --- | --- | --- |
| GEMINI_API_KEY | 없음 | 서버 전용 API 키 |
| GEMINI_MODEL | gemini-3.5-flash-lite | Gemini JSON 구조화 응답 지원 모델 |
| PORT | 3100 | 로컬 포트 |
| MAX_CALLS | 30 | 현재 서버 프로세스의 AI 호출 시도 상한 |

서버는 `127.0.0.1`에서만 접근하도록 구성했습니다. `.env`는 Git 제외 및 정적 파일 제공 대상 제외입니다. API 키·원본 오류·질문 내용은 로그에 기록하지 않습니다.

## 동작 구조

1. 서버가 공개 `hummman-pt` 저장소에서 `@prismicio/client` 7.x의 `getAllByType('workpage')`로 전체 프로젝트를 조회합니다. 개수는 고정하지 않습니다.
2. 문자열 및 리치텍스트 배열을 일반 텍스트로 정리합니다. HTML 엔티티를 처리하고 스크립트·스타일·이미지를 제외합니다. 브라우저에서도 CMS 및 AI 텍스트는 `textContent`로만 표시합니다.
3. `Works.js`의 `order` 숫자 내림차순, falsy 값의 999999 대체, 동일 값의 기존 순서를 그대로 따릅니다. 서버가 정렬 index+1로 상세 링크를 생성합니다. 매 검색마다 최신 데이터를 조회합니다.
4. 질문과 프로젝트 ID·제목·클라이언트·작업 종류·서비스·설명만 Gemini generateContent API에 전달합니다. 이미지·영상·상세 URL은 모델 입력에서 제외합니다. 별도 DB, 모델 학습, 외부 웹 검색, 이전 대화는 사용하지 않습니다. 무료 등급의 입력·응답은 Google 제품 개선에 사용될 수 있습니다.
5. 엄격한 JSON schema로 최대 3개 ID·추천 이유·원문 근거를 받습니다. 서버가 ID 존재, 중복, 개수, 문자열 길이 및 근거가 실제 필드에 포함되는지 다시 검증합니다. 하나라도 유효하지 않으면 전체 결과를 오류 처리합니다. 제목·이미지·URL은 서버의 실제 데이터로 결합합니다.
6. 썸네일·프로젝트명·추천 이유·원문 근거·상세 링크를 표시합니다. 로딩, 키 없음, 데이터 실패, AI 실패, 결과 없음 상태를 구분합니다.

## 제한과 사용량

- 질문 1~500자, 요청 본문 최대 4KB, 동시 AI 검색 1개, 전체 프로세스 기준 분당 5회, 실행당 기본 30회입니다.
- Gemini 요청은 45초, 최대 출력은 4,096토큰입니다. 응답이 중단되거나 거절되면 결과를 표시하지 않습니다. 자동 AI 재시도는 없습니다.
- 추천 이유는 200자, 원문 근거 및 안내는 각 240자로 제한합니다. 카탈로그가 예기치 않게 커지면 묵시적으로 자르지 않고 오류로 중단합니다.
- 화면 하단과 `GET /api/status`에 호출 시도·완료·실패 횟수, 실제 API 응답의 입력·출력 토큰 합계를 표시합니다. 서버 재시작 시 초기화됩니다.
- API가 사용량 응답을 반환하기 전에 네트워크가 끊기면 해당 토큰은 로컬 합계에 반영되지 않을 수 있습니다. 최종 청구 사용량은 Gemini 대시보드에서 확인하세요.
- 메모리 기반 제한은 분산 환경의 전체 사용량 상한이 아닙니다. 공개 서비스로 전환하기 전에는 인증, 공유 저장소 기반 제한, 비용 한도를 추가해야 합니다.

2026-10-20 공식 요금표 기준 gemini-3.5-flash-lite는 무료 등급 입력·출력 무료입니다. 무료 한도와 사용 가능 여부는 AI Studio에서 확인하세요. 무료 등급 한도 초과 시 자동으로 다른 유료 모델로 전환하거나 재시도하지 않습니다. 결제가 연결된 프로젝트의 과금을 이 앱이 판별하거나 차단하지는 못합니다.

## 검증

```powershell
npm test
npm run check:data
```

자동 테스트는 네트워크 AI 호출 없이 주입한 응답으로 정렬·HTML 정리·허위 ID·중복·개수·원문 근거·API 요청·토큰 집계·키 미설정·입력 제한·호출 상한·오류 응답·비밀정보 비노출을 확인합니다. 데이터 확인 명령은 공개 Prismic 및 사이트만 읽으며 `.env`를 로드하거나 Gemini를 호출하지 않습니다.

실제 검증 결과:

- `npm install`: 의존성 설치 완료, 취약점 0개.
- `npm test`: 6개 테스트 통과.
- `npm run check:data`: 공개 프로젝트 30개 조회. 첫 문서의 title/client/project/service/order는 문자열, description은 리치텍스트 배열, 썸네일은 객체였습니다. 필드별 정규화를 적용했습니다.
- 실제 사이트 `/works/20`에서 HAEGIN 제목과 서비스가 표시되며, 공개 사이트 작업 목록의 프로젝트별 링크가 데모의 30개 정렬과 일치하는 것을 브라우저에서 확인했습니다.
- 로컬 브라우저에서 예시 질문 입력 및 검색 시 키 미설정 안내를 확인했습니다.
- **실제 Gemini 호출 및 추천 정확도 테스트는 실행하지 않았습니다.** 키 설정 후 아래 질문을 소수부터 직접 실행하세요.

권장 확인 질문: 화장품 업체 웹사이트 / 뷰티 브랜드 쇼핑몰 / 게임 회사 홈페이지 / 디자인과 개발을 함께 한 프로젝트 / 데이터에 없는 업종 / 제작비나 성과 질문. 특정 정답을 하드코딩하지 않았습니다.
